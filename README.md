## Development Approach

Good front-end work starts with the HTML. A well-structured document reduces the need for ARIA workarounds, performs better in assistive technologies, and makes styles and scripts easier to apply predictably. From there, CSS handles presentation without leaking into component logic, and React handles interactivity without fighting the platform.

Code is written to be read by the next person — or by a future self returning after a long break. That means favouring explicit over clever, keeping components small and focused, and treating a clear commit history as part of the deliverable.
